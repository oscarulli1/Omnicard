## 🚀 Cómo Usarla y Publicarla

### 1. Probarla en tu computadora o celular local:
Solo haz doble clic en `index.html` o ábrelo con tu navegador preferido.

### 2. Publicarla gratis en internet en 2 minutos:
Puedes subir esta carpeta a:
* **Vercel** (`vercel deploy`) -> te da un enlace tipo `oscar-omniflow.vercel.app`
* **Netlify** (arrastrar y soltar la carpeta)
* **GitHub Pages**
* O vincularla a tu propio dominio: `tarjeta.omniflow.com` o `omniflow.me/oscar`.

### 3. Usarla como plantilla para tus clientes:
Para venderle una a un cliente (médico, abogado, broker inmobiliario):
1. Duplica esta carpeta.
2. Abre `script.js` y actualiza el objeto `profileData` con sus datos.
3. Actualiza sus textos en `index.html`.
4. ¡Listo para cobrar y entregar en menos de 30 minutos!
